# Le Fenouil Rouge – démo

**Site de démonstration – entreprise fictive.** Bistrot lyonnais imaginaire (Lyon 2e) : accueil avec carte, page de réservation (formulaire sans envoi), mentions.

- **Stack :** HTML / CSS / JavaScript, sans framework ni bibliothèque tierce. Polices auto-hébergées. Hébergement Cloudflare (Workers, assets statiques).
- **Site en ligne :** https://demo-restaurant-fenouil-rouge.atelier-requena.workers.dev
- **En local :** `python3 -m http.server` à la racine, puis http://localhost:8000
- **Crédits photo et polices :** voir [CREDITS.md](CREDITS.md).

Le restaurant, sa carte, ses prix et ses coordonnées sont fictifs. Le site est volontairement non indexé (`noindex`).
